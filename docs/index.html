Your code. Your machine. Your rules.

A tiny, self-hosted Git server for your trusted home network. No cloud, no accounts, no complexity.

Install homegit

$ curl -fsSL https://raw.githubusercontent.com/chris-roerig/homegit/main/install.sh | sh click to copy

Paste that in a macOS Terminal or Linux shell. Prefer Homebrew? Run brew install chris-roerig/homegit/homegit. Then homegit setup.

homegit init
homegit start
homegit clone
homegit list
homegit backup
homegit doctor
and more…

01 Stay local.

Keep your side projects on your own machine. Work offline and share across computers on your trusted network.

02 Keep it simple.

A single binary with an embedded SSH server. No separate database, accounts, or web dashboard to maintain.

03 Just use Git.

Initialize, push, and clone with familiar commands. Repositories are created automatically on first push.

04 Update in place.

Installed via the shell script? Run homegit update. Installed via Homebrew? Use brew upgrade.

Single computer

Host repositories on the machine you're using. During setup, choose “store repos on this computer.”

$ homegit setup            # choose: on this computer
$ homegit start            # homegit 1.3.0: server started

$ cd my-project
$ homegit init
$ git add . && git commit -m "Initial commit"
$ git push -u origin main

Connect to another computer

Point this machine at another computer that acts as the server. Set up the server first, then connect as a client.

# on the SERVER machine
$ homegit setup            # choose: on this computer
$ homegit start

# on THIS (client) machine
$ homegit setup            # choose: on another computer → 10.0.0.142
$ homegit list             # repos on 10.0.0.142
$ homegit clone

Built for trusted networks, not the public internet. homegit does not authenticate users: anyone who can reach its server can push and pull. Keep it on localhost or a private trusted network, and use firewall rules or a VPN as appropriate. Run homegit doctor anytime to check configuration and connectivity.
